## 통합 결정

- 원본의 로컬 AI 번역, 화면 주사율 기반 가사 이동·채움, 바이닐 회전과 곡 전환, 모바일 배경·가로 화면 설정, 네이티브 설정·가사 팝업 수정과 UI 테스트를 가져왔다.
- Xcode에서 같은 식별자를 사용하던 `LyricsProviderCore`와 `LlamaCpp` 등록을 분리했다. 포크의 앱 단위 테스트와 원본의 UI 테스트를 공유 scheme에서 모두 실행한다. 로컬 서명용 xcconfig 연결은 유지한다.
- 가사 공급자의 표준/다중 모드, 모드별 우선순위·유형·싱크 설정, 원격 정책과 Deezer 인증은 포크의 계약을 유지한다. 로컬 AI 모델·프로세서·유휴 설정은 별도로 저장하고 클라우드 설정에서 제외한다.
- 원본의 연속 재생 위치와 애니메이션을 적용하면서 포크의 겹침 가사, 누적 보컬 종료 시점 기반 자동 간주, 행 렌더 입력 캐시, PiP 설정을 보존한다.
- 번역은 로케일·키 단위로 병합해 포크 전용 문자열과 원본 신규 문자열을 함께 유지한다.
- 릴리스 검사는 계속 태그 대상 worktree를 기준으로 실행하며, 로컬 AI·배경·바이닐·간주·설정 UI 회귀 검사를 추가한다. IPA에는 실제 llama.cpp 프레임워크가 포함되어야 하고 Debug 설정 UI fixture는 제외되어야 한다.
- 원본의 호스트 검사 중 포크와 구조가 다른 로컬 AI helper 추출과 간주 검사는 같은 동작 계약을 검사하도록 조정한다.
